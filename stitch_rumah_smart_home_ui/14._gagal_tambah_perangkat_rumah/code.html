Gagal Menghubungkan

3 kondisi kegagalan pairing dan penanganannya:

wifi_off

Sandi WiFi salah

Alat tidak dapat terhubung ke jaringan 'Rumah-Utama'.

Periksa kembali kata sandi WiFi dan coba hubungkan lagi.

timer_off

Kode pairing kedaluwarsa

Batas waktu 10 menit kode pairing telah habis.

Buat kode pairing baru dan tekan tombol BOOT pada alat.

cloud_off

Server tidak terjangkau

Modul terhubung ke WiFi tetapi tidak merespons server lokal.

Pastikan gateway server rumah menyala dan dalam subnet yang sama.
