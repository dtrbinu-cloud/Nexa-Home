# Camera App (Aplikasi Kamera HP Bekas) — Smart Home "Rumah"

Direktori ini dipersiapkan untuk **Tahap 4 (Kamera dari HP Bekas)**.

## Rencana Implementasi
1. PWA satu halaman responsif untuk dijalankan di browser mobile HP Android bekas.
2. Mengirimkan video WebRTC (WHIP) ke MediaMTX di server lokal.
3. Fitur hemat daya, Screen Wake Lock API (layar tetap aktif tanpa tidur), indikator visual kamera aktif, dan auto-reconnect saat jaringan Wi-Fi berkedip.
